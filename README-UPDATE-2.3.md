# CARGOGO 2.3 — обновление личного кабинета

## Что добавлено
- Переключение языка RU / RO непосредственно в шапке личного кабинета. Выбор языка сохраняется в `localStorage` и синхронизирован с главной страницей через ключ `cargogo-language`.
- Переведены основные разделы кабинета, формы, навигация, статусы и динамически добавляемые подписи.
- Добавлена загрузка фото профиля JPG, PNG или WebP до 2 МБ.
- Фото проверяется по MIME-типу и сигнатуре файла, имя генерируется случайно, маршрут защищён авторизацией и ограничением частоты загрузок.
- URL фото сохраняется в `users.avatar_url`; столбец добавляется автоматически при запуске сервера.
- Улучшены мобильные правила для шапки, карточки профиля, форм, чата и нижней навигации.

## Установка
1. Распакуйте обновление поверх копии проекта или замените файлы одноимёнными.
2. Сохраните свой `.env`.
3. Выполните `npm install`, если зависимости ещё не установлены.
4. Запустите `npm start`.

База данных не пересоздаётся. При старте сервер добавит `users.avatar_url`, если столбца ещё нет.

## Фото профиля
Загруженные файлы сохраняются в `public/uploads/`. Каталог создаётся автоматически. Разрешены JPEG, PNG и WebP; SVG и GIF не принимаются. Ограничение — 2 МБ и 5 попыток за 15 минут на пользователя.

## Примечание
Синтаксис JavaScript и базовая структура CSS проверены. Реальный вход, загрузка файла и SQL-миграция требуют запуска с вашей PostgreSQL и проверки в браузере/на телефоне.
