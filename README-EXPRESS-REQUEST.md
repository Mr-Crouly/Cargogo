# Обновление CARGOGO: экспресс-заявки без регистрации

## Что добавлено
- На главной странице появилась кнопка «Экспресс-заявка».
- Посетитель может оставить имя, телефон, адрес отправления и доставки, описание груза и желаемую дату без создания аккаунта.
- Заявка сохраняется в PostgreSQL в таблицу `express_requests`.
- В админ-панели добавлен раздел «Экспресс-заявки»: просмотр контактов и маршрута, фильтр по статусу и перевод заявки в статусы «Новая», «В работе», «Завершена».
- Форма поддерживает русский и румынский языки.
- Добавлено ограничение частоты отправки с одного IP и скрытое поле против простых спам-ботов.

## Установка
1. Сделайте резервную копию текущей папки проекта и базы PostgreSQL.
2. Распакуйте архив и скопируйте содержимое папки `Cargogo/cargogo` поверх своей папки проекта.
3. Не заменяйте свой `.env`: в архив он намеренно не включён. Сохраните свои параметры PostgreSQL и `JWT_SECRET`.
4. В корне проекта выполните `npm install` (если зависимости уже установлены, можно пропустить).
5. Запустите `npm start`. При запуске сервер автоматически создаст таблицу `express_requests` и индекс, если их ещё нет.
6. Откройте главную страницу, обновите её через Ctrl+F5 и проверьте отправку тестовой заявки.
7. Войдите в админ-панель и откройте раздел «Экспресс-заявки».

## Важно
- Полноценная отправка email/SMS не настроена: заявка сохраняется в базе и доступна администратору в панели.
- Ограничитель частоты хранится в памяти процесса и сбрасывается после перезапуска сервера. Для нескольких экземпляров приложения нужен общий rate-limit store.
- Перед публикацией настройте политику конфиденциальности и срок хранения контактных данных.
