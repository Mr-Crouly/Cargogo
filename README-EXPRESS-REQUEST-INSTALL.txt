CARGOGO — УСТАНОВКА ЭКСПРЕСС-ЗАЯВКИ

1. Сделайте резервную копию папки проекта и базы PostgreSQL.
2. Распакуйте архив.
3. Откройте папку Cargogo/cargogo внутри архива.
4. Скопируйте ЕЁ СОДЕРЖИМОЕ (папки public и файлы server.js, package.json и т.д.) в корень ВАШЕГО проекта — туда, где находится ваш server.js.
   Не копируйте внешнюю папку Cargogo поверх public и не создавайте второй уровень cargogo/cargogo.
5. Сохраните свой локальный .env. Он не включён в архив.
6. В терминале, находясь в корне проекта, выполните npm install (если зависимости уже установлены, обычно можно пропустить), затем npm start.
7. Откройте тот же адрес, на котором обычно работает CARGOGO (сервер выводит адрес в терминал), затем нажмите Ctrl+F5.
8. На главной странице в правом блоке поиска под строкой поиска появится блок «Нужна перевозка срочно?» и кнопка «Экспресс-заявка».
9. После отправки заявка сохраняется в PostgreSQL. В админ-панели откройте пункт «Экспресс-заявки».

Если кнопки нет:
- Убедитесь, что сервер запущен из той папки, куда вы скопировали обновлённые файлы.
- Проверьте, что файл public/index.html в этой папке содержит id="openExpressBtn".
- Проверьте, что public/script.js содержит /express-requests.
- Откройте DevTools (F12) → Console и посмотрите, нет ли ошибок загрузки script.js.

Важно: .env, .git и node_modules намеренно исключены. Архив содержит исходники приложения, а не готовую базу данных.
Email/SMS-рассылка не подключена; заявки доступны в админ-панели.
